# PadRemote downloads

Official PadRemote Host and client release downloads. This repository contains release artifacts and download information only; application source code is maintained separately.

Release candidates are marked **Pre-release**. They are not automatically installed by stable Host updates. A stable download will appear in Releases after validation.

Host 0.11.0 introduces automatic updates for Windows, macOS and Linux. Install the new launcher once, then keep it: updates download in the background and install after tablet connections and project terminals are closed. The previous version is restored if the update fails its startup check. Host settings and projects are kept separately.

The updater verifies a publisher-signed manifest and SHA256 digests. This update signature is separate from Windows Authenticode and Apple Developer ID/notarization. Engineering previews may be unsigned; their release notes state platform signing and testing status explicitly.

Only download artifacts from this repository's Releases. No GitHub account or access token is needed to download public releases. Never provide AI credentials, project contents or Host configuration files to this repository.
